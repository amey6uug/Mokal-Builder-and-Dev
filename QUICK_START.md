# Quick Start

## Prerequisites
- Node.js 18+
- npm

## Install
```bash
npm install
```

## Run
```bash
npm run dev
```

## Open
- `http://localhost:3001`

## Edit
- HTML pages: `public/html/`
- Global styles: `public/css/style.css`
- Scripts: `public/js/`
- Routes: `server.js`

## Stop
Press `Ctrl+C` in the terminal running the server.
